# G4-I0 Spike: ทดสอบเคอร์เซอร์เสมือนด้วยจอยจริง

ฉากทดลองชั่วคราว (ลบทิ้งได้ทั้งโฟลเดอร์หลังตัดสินใจ) ใช้ตอบข้อ A3 ใน `Docs/rewrite/R1_OwnerChecklist.md`

- ฉาก: `Assets/Bar410/Spikes/G4I0/G4I0_Spike.unity` (ไม่ได้อยู่ใน Build Settings)
- โค้ด: `G4I0Spike.cs` (สร้าง UI ทั้งหมดตอน Play) + `SpikeClickTarget.cs` ในโฟลเดอร์เดียวกัน
- ใน Edit mode ฉากมีแค่ GameObject `[G4I0Spike]` ปุ่ม กล้อง และกล่องต่างๆ จะโผล่ตอนกด Play

## วิธีเปิด
1. ต่อจอยก่อนเปิด Unity หรือก่อนกด Play
2. เปิดฉาก `G4I0_Spike` แล้วกด Play
3. **คลิกในหน้าต่าง Game หนึ่งครั้ง** (ให้ Game view ได้ focus และ HUD ขึ้นว่า `Last device: Mouse`) แล้วค่อยจับจอย
4. แนะนำให้ตั้ง Game view เป็น 1920x1080 หรือ Full HD (Maximize On Play ก็ได้)

## สิ่งที่ต้องลอง (ตรงกับ A3)
1. **จอย Xbox:** ขยับ stick ซ้าย เคอร์เซอร์สีเหลืองต้องลื่น ไม่กระตุก และปล่อย stick แล้วต้องหยุดนิ่ง (ไม่ลอยเอง) ดูบรรทัด `LS raw` ตอนปล่อยมือ ถ้าเคอร์เซอร์ลอย ให้เลื่อน slider `Cursor dead zone` ขึ้นจนหยุด แล้วจดค่าไว้ ปรับความเร็วได้ด้วย slider `Cursor speed`
2. **จอย PlayStation (ถ้ามี):** ทำข้อ 1 ซ้ำ บรรทัด `Last device` ควรเป็น `PlayStation`
3. **กดปุ่ม uGUI:** เลื่อนเคอร์เซอร์ไปที่ `Button A/B/C` แล้วกด A (Xbox) / X (PS) ตัวเลขต้องเพิ่มทีละ 1 ไม่ใช่ 2
4. **คลิกผ่าน RenderTexture:** เลื่อนเคอร์เซอร์ไปที่กล่องในภาพตรงกลาง แล้วกด A / X กล่องที่โดนต้องเป็นสีขาว และ Log ขึ้นชื่อกล่อง
5. **ตอน Pause:** กด Start / Options (หรือปุ่ม `Pause`) ให้ `timeScale: 0` แล้วทำข้อ 3 และ 4 ซ้ำ เคอร์เซอร์ต้องยังขยับและกดได้ กด Start อีกครั้งเพื่อเล่นต่อ
6. **สลับกลับเป็นเมาส์:** ขยับเมาส์จริง เคอร์เซอร์เหลืองต้องหาย และลูกศรเมาส์ของระบบกลับมา แตะจอยอีกครั้ง เคอร์เซอร์เหลืองกลับมาตรงตำแหน่งเมาส์ และลูกศรระบบหาย
7. **stick ขวา:** ลอง 2 แบบ แล้วบอกว่าแบบไหนดีกว่า
   - **แตะ** (ดันสุดแล้วปล่อยภายใน 0.25 วินาที) ขึ้น `RS TAP -> next view` (แตะ = เปลี่ยนมุมกล้อง)
   - **ค้าง** (ดันค้างเกิน 0.25 วินาที) ขึ้น `RS HOLD -> peek` และตอนปล่อยขึ้น `back to Forward` (ค้าง = แอบมอง)
   - เอาเคอร์เซอร์ไปวางบนรายการ `Row 01..20` แล้วดัน stick ขวา รายการต้องเลื่อน
8. **ปุ่มที่รู้สึกไม่ถนัด:** จดไว้ (ใช้ตอบ B2) บรรทัด `Buttons pressed` จะบอกชื่อปุ่มที่กดอยู่

## HUD แต่ละบรรทัด
| บรรทัด | ความหมาย |
|---|---|
| `Last device` | อุปกรณ์ที่ใช้ล่าสุด (Mouse / Keyboard / Xbox / PlayStation / Other) ไม่นับเมาส์เสมือน บรรทัดถัดไปคือชื่อจอยและ layout (ใช้เป็น "ชื่อจอยที่ใช้" ในผลที่ส่งกลับ) จอย Xbox บน Linux อาจขึ้นเป็น `Other` ได้ ไม่ถือว่าผิด แค่จดไว้ |
| `Hardware cursor visible` / `Software cursor` | ลูกศรเมาส์ของระบบ / เคอร์เซอร์เหลือง (ควรเห็นแค่อันเดียว) |
| `Mouse.current`, `ignored VirtualMouse events` | ข้อมูลภายใน ไม่ต้องสนใจ |
| `Virtual cursor` | ตำแหน่งเคอร์เซอร์เสมือนเป็น pixel และขนาดจอ (ต้องไม่หลุดขอบจอ) |
| `LS raw` → `cursor` | ค่าดิบของ stick ซ้าย → ค่าที่ใช้ขยับเคอร์เซอร์หลังตัด dead zone |
| `RS raw` → | ค่าดิบของ stick ขวา → ค่าหลังตัด dead zone |
| `Dead zone` | ค่า slider (ซ้อนกับค่าเริ่มต้นของ Input System 0.125 ที่ใช้อยู่แล้ว) |
| `Max raw LS while cursor still` | ค่าดิบสูงสุดที่ dead zone กลืนไป (ถ้าใกล้ค่า dead zone แปลว่าจอยลอยเยอะ) |
| `Buttons pressed` | ปุ่มจอยที่กดอยู่ตอนนี้ |
| `timeScale` | 1 = เล่นปกติ, 0 = Pause |
| `Right stick` | ผลแตะ/ค้างล่าสุดของ stick ขวา |
| `Clicks` | จำนวนครั้งที่กดปุ่ม A/B/C |
| `Checklist` | ติ๊ก `PASS` เองอัตโนมัติ นับเฉพาะการกดด้วยเคอร์เซอร์เสมือน (กดด้วยเมาส์จริงไม่ติ๊ก) |
| `Log` | เหตุการณ์ล่าสุด 12 บรรทัด |

## ส่งผลกลับ
1. ทดสอบครบแล้วกด **C** บนคีย์บอร์ด หรือปุ่ม **Select / View / Share** บนจอย หรือปุ่ม `Copy HUD` ข้อความ HUD ทั้งหมดจะถูก copy ลง clipboard (และพิมพ์ลง Console)
2. วางข้อความนั้นในแชท 1 ครั้งต่อจอย 1 ตัว
3. เขียนเพิ่มเองสิ่งที่ HUD ตัดสินไม่ได้: เคอร์เซอร์ลอยไหม ลื่นไหม ค่า dead zone / speed ที่ชอบ แตะหรือค้างดีกว่า และปุ่มที่ไม่ถนัด
