## C. ตรวจภาษาไทยด้วยตา (รอ UI/presenter ใหม่ — R4 ขึ้นไป ยังทำไม่ได้ตอนนี้)

ต้องมีฟอนต์ไทย (มีแล้ว) **และ** ตั้ง font features `kern, mark, mkmk` ในทุก TMP ที่แสดงไทย **และ** presenter จริง ผมจะแจ้งเมื่อพร้อม รายการจาก `Spike_G2-T02_Results.md`:

- [x] C1. สระ/วรรณยุกต์ซ้อน ไม่ทับกันเมื่อเปิด `mark`+`mkmk`: ที่ ปั้น น้ำ กุ้ง ปู่ ป่ ฟ้า ฝั่ง และไม่ถูกบรรทัดบนตัดทอน
- [x] C2. เทียบกับเปิดแค่ `kern`: เห็นความต่างจริงไหม (ถ้าไม่เห็น ตัวเลขที่วัดอาจทำให้เข้าใจผิด)
- [x] C3. ตัดบรรทัดเฉพาะที่ ZWSP ที่นักแปลใส่ ไม่มีวรรณยุกต์เดี่ยวต้นบรรทัด
- [x] C4. Text Animator `[wave]` `[wiggle]` `[dangle]` บนไทย: วรรณยุกต์/สระขยับไปกับพยัญชนะ ไม่ลอยแยก
- [x] C5. Typewriter โหมด Character: วรรณยุกต์ขึ้นพร้อมพยัญชนะ ไม่ช้ากว่าหนึ่งจังหวะ
- [x] C6. โหมด Word กับไทย (ไม่มีวรรค มีแค่ ZWSP): เผยทีละชิ้น หรือทั้งบรรทัดทีเดียว
- [x] C7. ความสูงบรรทัด/ส่วนห้อย (ปู่ กุ้ง) อยู่ในกล่อง ต้องปรับขนาด/line spacing ไหม
- [x] C8. สลับ EN↔TH ระหว่างพิมพ์, หลังพิมพ์จบ, และสลับรัว 5 ครั้ง: พิมพ์ใหม่ `[wave]` ไม่หาย เสียงไม่เริ่มใหม่

ผลของ C4 และ C6 ตัดสินว่าต้องทำ G2-T18 (แก้การตัดคำ/effect ไทย) หรือไม่
