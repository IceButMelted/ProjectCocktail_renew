## ส่วน C — เป้าหมายเพิ่มเติม: หลายภาษา

### C1. ภาษาที่ต้องรองรับ
- มีกี่ภาษา และคือภาษาอะไรบ้าง?
- ภาษาต้นฉบับที่ writer เขียนใน Yarn คือภาษาอะไร?
- มีภาษาที่ต้องใช้ฟอนต์พิเศษ/ตัวอักษรที่ไม่ใช่ละติน (ไทย, ญี่ปุ่น, จีน, เกาหลี, อาหรับ ฯลฯ) ไหม?

**คำตอบ:** 
- ตอนนี้อยากรองรับก่อน 2 ภาษาคือ ENG และ THAI 
- ต้นฉบับภาษาคือภาษาอังกฤษ
- มี THAi ที่ต้องใช้ฟอร์นพิเศษ

### C2. ใครแปล และแปลอย่างไร
- แปลโดยตัวเอง / จ้างภายนอก / ใช้ AI ช่วย?
- ต้องการรูปแบบไฟล์ส่งให้ผู้แปล (CSV/Spreadsheet/XLIFF) แบบไหน?
- ต้องเปลี่ยนภาษาระหว่างเล่นได้ทันที (ไม่ต้องรีสตาร์ท) ไหม?

**คำตอบ:**
- แปลโดยใช้ Outsource 
- CSV ตาม Format ของ Yarn แต่ตอนรับงานจะรับมาจากเป็น Spreadsheet
- ต้องเปลี่ยนภาษาระหว่างเล่นได้ทันที 

### C3. ข้อความนอก Yarn
ข้อความเหล่านี้ต้องแปลด้วยไหม (ติ๊กที่ต้องแปล): 
- [/] UI ทั้งหมด (ปุ่ม, Settings, Pause)
- [/] ชื่อ Chapter / Event popup
- [/] ชื่อเครื่องดื่ม / วัตถุดิบ / คำอธิบายสูตรในหนังสือ
- [/] ชื่อตัวละคร
- [/] ข้อความใน Garnish / Minigame
- [ ] อื่นๆ:

**คำตอบ / หมายเหตุ:** นอกจากนี้ยังมี internal ที่อยากให้เปลี่ยนด้วยเพราะการสั่งเครื่องดื่มนีั่นจะมีการสั่งแบบ Detailed ซึ่งตอนนี้มีแค่ภาษาอังกฤษ ซคางมันไปดึงข้อมูลจาก SO_ ที่เขียนไว้มาใช้ 

### C4. ข้อความในภาพ
มีรูปที่มีตัวอักษรอยู่ในภาพ (ป้าย, โน้ต, หนังสือ) ที่ต้องทำเวอร์ชันแยกตามภาษาไหม?

**คำตอบ:** มี

## ส่วน D — เป้าหมายเพิ่มเติม: Voice Over

### D1. ขอบเขตเสียง
- [ ] ทุกบรรทัดของทุกตัวละคร
- [/] เฉพาะบรรทัดสำคัญ (ระบุเกณฑ์):
- [ ] เฉพาะบางตัวละคร:
- [ ] ยังไม่แน่ใจ

**คำตอบ:** ทุก Expresssion โดยจะเป็นเพีบงเสียงแบบ *Sign* *HUH!?* ประมาณนั้น ไม่ใช้พูดทั้งประโยค 

### D2. ภาษาของเสียง
- เสียงมีภาษาเดียวหรือแยกตามภาษา (ผู้เล่นเลือกภาษาข้อความ และภาษาเสียงแยกกันได้ไหม)?
- ถ้าบางภาษาไม่มีเสียง ให้ทำอย่างไร (เงียบ / ใช้เสียงภาษาอื่น)?

**คำตอบ:** ให้ใช่เสียงเดียวไปตลอดไม่ว่าจะใช้ภาษาไหน

### D3. พฤติกรรมตอนเล่น
- เสียงต้องหยุดเมื่อกดข้ามบรรทัดหรือไม่?
- AutoPlay ต้องรอเสียงจบก่อนไปบรรทัดถัดไปไหม?
- Skip ที่มีอยู่ (ข้ามบทที่เคยอ่านแล้ว) ต้องข้ามเสียงด้วยไหม?
- ต้อง sync ปากตัวละครหรือท่าทางกับเสียงไหม?
- Text Animator ที่พิมพ์ทีละตัวอักษร ต้องปรับความเร็วให้ตรงกับความยาวเสียงไหม?

**คำตอบ:** 
- เสียงต้องหยุดเมื่อกดข้ามบรรทัด
- AutoPlay ต้องรอเสียงจบก่อนไปบรรทัดถัดไป, 
- ข้ามเสียงของบทสนทนาที่เล่นไปแล้ว, 
- ต้อง sync ปากตัวละครหรือท่าทางกับเสียง
- Text Animator ที่พิมพ์ทีละตัวอักษร ไม่ต้องปรับความเร็วให้ตรงกับความยาวเสียง

### D4. วิธีจัดการไฟล์เสียง
- เสียงมาจากไหน (บันทึกเอง / นักพากย์ / AI)? ตอนนี้มีไฟล์แล้วหรือยัง?
- ผูกกับบรรทัดอย่างไร: ใช้ line ID ของ Yarn (`#line:xxx`) ตั้งชื่อไฟล์ตาม ID หรือ tag เสียงใน Yarn โดยตรง?
- ต้องการเครื่องมือช่วยตรวจ "บรรทัดไหนยังไม่มีเสียง" ตอน build ไหม?

**คำตอบ:**
- เสียงมาจาก บันทึกเอง มีนักพากย์ และใช้ AI ยังไม่มีใช้ตอนนี้
- ใช้เป็น Command In Line ของ Yarn ในการเล่นเสียงผ่าน ID ของเสียง
- ยังไม่ทำเครื่องมือช่วยตรวจ "บรรทัดไหนยังไม่มีเสียง" เพราะตอนนี้ใช้แค่ เสียงในการ Expression เฉยๆไม่ใช่ Voice Over ทั้ง Line

## ส่วน E — เป้าหมายอื่นที่ยังไม่ได้บอก

### E1. แพลตฟอร์ม
Windows/Mac/Linux, console, mobile? มีแพลตฟอร์มใหม่ที่จะเพิ่มทีหลังไหม (มีผลกับ Input และ UI)

**คำตอบ:** Windows/Linux/Console(ไม่ทำลงจริงเพียงแค่อยากทำ Controll ให้รองรับไว้ก่อน)

### E2. ขนาดเนื้อหาที่วางแผน
จำนวนวัน / ตัวละคร / สูตรเครื่องดื่ม / วัตถุดิบ ที่ตั้งใจจะทำ (ใช้ประเมินว่าต้องมีเครื่องมือช่วย writer/designer มากแค่ไหน)

**คำตอบ:** 21 วัน 8 ตัวละคร, 28 สูครเครื่องดื่มปกติ, 8 สูตรเครื่องดิ่มพิเศษ, วัตถุดับ 5 อย่างสำหรับ Base Spirit, 4 Liqueurs 8 Mixer, แต่ละเมนูมี Description สำหรับการสั่งแบบ Detailed 

### E3. ใครจะเพิ่ม feature และเนื้อหา
มี writer, designer ที่ไม่เขียนโค้ดมาแก้ Yarn/Inspector เองไหม (มีผลกับเครื่องมือตรวจ Yarn และ Inspector ของลิสต์ `steps`)

**คำตอบ:** Programmer(ผม) เป็นคนเพิ่มและแก้ โดย Designer เป็นคนสั่งลงมาให้ผมแก้

### E4. Save/Load
- ยืนยันว่ายังใช้แนวทาง "Save ที่บรรทัดปัจจุบัน + silent replay" และไม่ save ใน Event ตามที่เคยตกลงไหม?
- มี save หลายช่อง (slot) ไหม และต้องมี autosave ไหม?
- save เวอร์ชันเก่า (ของเดโมปัจจุบัน) ต้องใช้ต่อได้ไหม หรือทิ้งได้?

**คำตอบ:**
- ยืนยัน
- มี Save หลาย Slot และมี Auto Save 
- Save Version เก่าทิ้งได้

### E5. Controller
Controller ต้องใช้ได้ทุกหน้าจอ (รวมมินิเกมและ Garnish) หรือเฉพาะบทสนทนาและเมนู? มีอุปกรณ์เป้าหมาย (Xbox, PlayStation, Switch, Steam Deck) ไหม

**คำตอบ:**
Controller ต้องใช้ได้ทุกหน้าจอ เป้าหมายจอยหลักคือ Xbox และ PlayStation
