# `MoveOut`

**ประเภท:** Command (รอ) · **กลุ่ม:** ลูกค้า (`TalkToCustomerManager`)

## วิธีเขียน
```
<<MoveOut NPC_Name.Isla>>
```

## Argument
`npc`: `NPC_Name.X`

## ทำอะไร
ให้ NPC เดินออก (waypoint 0) บทรอจนเดินถึง

## ใช้ได้เมื่อ
ได้ทุกเมื่อ

## หมายเหตุ
ระหว่าง silent replay ไม่เดิน
