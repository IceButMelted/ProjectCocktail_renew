# `Fade_To_Summmary`

**ประเภท:** Command (instance, รอ) · **กลุ่ม:** UI / transition / ระบบอื่น

## วิธีเขียน
```
<<Fade_To_Summmary Panel_Transition>>
```

## Argument
target: `Panel_Transition`

## ทำอะไร
เล่น transition ไปหน้าสรุป บทรอจนจบ

## ใช้ได้เมื่อ
ท้ายวัน

## หมายเหตุ
ชื่อสะกด `Summmary` (m สามตัว) ตามโค้ด ห้ามแก้ชื่อเพราะ yarn เดิมใช้อยู่
